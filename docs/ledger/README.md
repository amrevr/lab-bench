# Lab Bench ledger

One short file per entry: `YYYY-MM-DD-<slug>.md`, front matter (date, author, type, repo, links),
then `# title` and at most ~15 lines. Types: finding, decision, gotcha, failure, plan.
Format follows the `ledger` plugin (amrevr/sbx-setup). Never put secrets here.
This branch holds only the ledger; code lives on `main`.
